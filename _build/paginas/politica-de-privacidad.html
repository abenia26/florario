Responsable del tratamiento

Florario – Calendario de flores es un proyecto personal. El responsable de los datos que se tratan en esta web es:

  • Titular: {{owner}}
  • Correo: {{email}}

Qué datos se tratan

  1. Datos técnicos de navegación. Como cualquier web, el servidor que aloja Florario registra datos técnicos de cada visita (dirección IP, navegador, página solicitada, fecha y hora) para servir la página y por seguridad. No los usamos para identificarte ni para hacer perfiles.
  2. Estadísticas de visitas. Usamos Vercel Web Analytics para saber cuántas personas visitan cada página, desde qué país, con qué tipo de dispositivo y desde qué web llegan. No usa cookies ni guarda nada en tu navegador: reconoce una visita con un identificador que se calcula a partir de la petición y se descarta a las 24 horas, así que no permite identificarte ni seguirte entre días o webs. Puede registrar también, sin datos personales, qué botones se pulsan (por ejemplo, descargar un recordatorio o compartir por WhatsApp).
  3. Fechas guardadas. Si marcas fechas con el corazón (“Guardar”), la lista se guarda solo en tu navegador mediante almacenamiento local (localStorage). Nunca se envía a ningún servidor y puedes borrarla limpiando los datos del sitio en tu navegador.
  4. Correos que nos envíes. Si nos escribes, usaremos tu dirección y tu mensaje solo para responderte.

Florario no usa cookies propias ni de terceros, ni para analítica ni para publicidad, y no tiene formularios de registro. Las tarjetas y los archivos de calendario con tus fechas guardadas se crean en tu propio navegador: no se envían a ningún servidor.

Servicios de terceros

  • Alojamiento: la web se aloja en Vercel Inc. (EE. UU.), que trata los datos técnicos de navegación como encargado del tratamiento. Vercel se acoge al Marco de Privacidad de Datos UE-EE. UU.
  • Estadísticas: Vercel Web Analytics, de Vercel Inc., trata los datos de las visitas descritos arriba como encargado del tratamiento.
  • Tipografías: las fuentes están alojadas en la propia web, así que no se pide nada a Google Fonts ni a otros servicios.
  • Enlaces externos: algunos botones llevan a TikTok, Google Calendar o a los medios citados como fuente. Al abrirlos se aplican las políticas de privacidad de esos sitios.
  • Recordatorios (.ics): los archivos de calendario se descargan a tu dispositivo; no sabemos quién los descarga ni recogemos ningún dato al hacerlo.

Base legal y conservación

Los datos técnicos y las estadísticas anónimas se tratan por interés legítimo en mantener la web disponible y segura y en saber qué contenidos son útiles, y se conservan el tiempo que determine el proveedor de alojamiento para esos fines. Los correos se tratan con tu consentimiento al escribirnos y se conservan mientras dure la conversación y, como máximo, un año después.
